1. 让 potential_confidence_threshold 真正生效

文件：
src/vln_nav/navigation/landmark_tracker.py

- observation.visible == True
- observation.reason == "ok"
- observation.is_current_frame == True

文件：
src/vln_nav/navigation/landmark_tracker.py
src/vln_nav/navigation/vln_policy.py

- depth_invalid 不能更新 potential anchor
- depth_invalid 不能增加 confirmed candidate count

- depth_invalid 不能被 _is_fresh_grounded_observation() 认为是可用于决策的 fresh target

也就是说，vln_policy.py 里的 _is_fresh_grounded_observation() 只接受：

reason == "ok"
visible == True
is_current_frame == True
depth_m is not None
estimated_world_xy is not None

3. 统一 qwen_fallback_confirm_allowed 配置来源

文件：
configs/default.yaml
src/vln_nav/runtime/config.py
src/vln_nav/app/nav.py
src/vln_nav/navigation/target_grounding.py
src/vln_nav/navigation/landmark_tracker.py

以 target_grounding.qwen_fallback_confirm_allowed 作为唯一有效来源。

configs/default.yaml 中放在：

target_grounding:
  qwen_fallback_confirm_allowed: false

runtime/config.py 只读取这一份。

nav.py 把这个值传给 TargetGroundingConfig。

LandmarkTracker 不应该再自己决定 Qwen 是否能 confirm；它只看 observation.can_confirm。

如果 LandmarkTrackerConfig 里还保留 qwen_fallback_confirm_allowed 字段，请标记为 deprecated 或删除，避免两个开关不一致。

验收标准：
Qwen bbox 默认只能 evidence_level="potential"，can_confirm=False。
GroundingDINO bbox 才能 can_confirm=True。

4. turn_at_complete_requires_confirmed_anchor 不能是死配置

文件：
src/vln_nav/navigation/vln_policy.py
src/vln_nav/app/nav.py
src/vln_nav/runtime/config.py

现在 turn_at_complete_requires_confirmed_anchor 配了，但策略里是硬编码行为。

修改要求：
OpenNavPolicyConfig 增加：

turn_at_complete_requires_confirmed_anchor: bool = True

nav.py 从 AppConfig 传入。

_turn_at_step() 中显式使用这个配置。

默认 true 时：
turn_at 只能在 tracker_state 满足以下条件时完成：

- tracker_state.evidence_level == "confirmed"
- tracker_state.can_complete == True
- tracker_state.estimated_world_xy is not None
- tracker_state.confirmed_observation_count >= confirm_min_observations
- tracker_state.confidence 或 confirmed_confidence >= confirm_confidence_threshold

[TurnAt] complete target=... reason=confirmed_anchor confidence=... obs=... distance=...

如果没完成，日志必须包含：
[TurnAt] not_complete target=... reason=potential/not_confirmed/too_far/no_anchor ...

文件：
src/vln_nav/navigation/vln_policy.py
src/vln_nav/navigation/landmark_map.py

src/vln_nav/navigation/landmark_tracker.py
